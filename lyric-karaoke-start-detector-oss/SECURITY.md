# Security Policy

## Supported Versions
This project is early-stage. Security fixes will be applied to the latest release on the `main` branch.

## Reporting a Vulnerability
If you believe you have found a security vulnerability, **please do not open a public GitHub issue**.

Instead, email the maintainers at: **<chowdhury.rafi01@gmail.com>**

Please include:
- A clear description of the issue
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

We aim to acknowledge reports within 72 hours.

## Disclosure
We follow coordinated vulnerability disclosure: we will work with you on a fix and then publish a disclosure note after a patch is available.
